## 硬件接入所需资料

- 头环产品型号、真实外观、额头接触与佩戴方式。
- GATT 服务/特征 UUID 完整定义，以及 iOS / Android SDK。
- 广播过滤方式、握手、控制指令、通知订阅、MTU 与断线重连规则。
- EEG/PPG 样本格式、大小端、采样率、校准系数、时间戳单位与丢包规则。
- CRC 多项式、初值、反射参数、计算范围及在帧中的位置。
- 电量、固件、信号质量和佩戴状态的真实编码。
- 睡眠阶段判定 SDK / 模型及验证证据。

下一轮建议先交付真实扫描 → 连接 → 设备信息 → 佩戴检测这一个完整硬件流程，再开展睡眠采集与报告。
