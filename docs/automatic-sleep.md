# 自动助眠体验

产品方向：用户佩戴头环后点击开始，由脑电状态驱动声音调整。主页以头环和自动助眠为主，问卷用于建立初始偏好，音乐列表用于可选的手动控制。

## 本轮实现

- 删除截图蓝框内的标题、日期与设备连接栏。
- 半透明卡片、柔和的蓝紫光晕、圆形玻璃按钮和悬浮导航。
- 首页只有一个主要按钮：开始助眠。
- 自动流程：佩戴确认 → 状态感知 → 自适应助眠 → 渐弱陪伴。
- 浏览器连续调节音频增益和低通滤波，避免直接中断声景。
- 原生声音切换采用淡出/替换/淡入，随后渐弱音量。
- 暂停冻结演示状态与计时；继续恢复；退出释放助眠播放器。

## 演示和真实产品的区别

疲劳度、紧张度、信号质量均由本地脚本生成，不是设备数据。阶段按演示时间推进，没有真实 EEG 分析，也不声称识别了入睡状态。当前音量渐弱后保持低音量，用户仍可手动结束。

真实接入时需要厂商输出的可信状态与信号质量，随后设计经验证的控制规则、连续多窗口确认、状态变化迟滞、丢失信号时的稳定声景策略，以及音量上限。不得直接用演示中的阈值当作临床睡眠分期规则。

## 验证

`qa-auto.mjs` 同时运行浏览器设计版和 React Native Web，检查自动播放、暂停恢复、声景切换、渐弱音量和退出。读取实际 Web Audio 增益/频率及 Expo 的 HTML 音频播放进度，避免只检验按钮文案。

原生毛玻璃使用 expo-blur；Android 和 iOS 的实际呈现、锁屏音频、蓝牙链路和真机扬声器仍需设备验收。
